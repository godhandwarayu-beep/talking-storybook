# นิทานพูดได้

แอปฝึกอ่านภาษาไทยกับพี่ฮูก ถ่ายรูปหน้าหนังสือแล้วฝึกอ่านออกเสียง คำที่อ่านถูกเปลี่ยนสีแบบคาราโอเกะ อ่านไม่ได้มีพี่ฮูกช่วยสะกด

เปิดใช้: https://godhandwarayu-beep.github.io/talking-storybook/

## สิ่งที่ทำได้

- **นิทานแบบด่าน**: ปกนิทาน → แผนที่ด่าน → อ่านจบด่านละหน้าเพื่อปลดล็อกด่านถัดไป → จบเรื่องมีพลุ เสียงปรบมือ และพี่ฮูกชมชื่อนักเรียนดัง ๆ
- **ลงชื่อด้วยรายชื่อห้อง + รหัส 4 ตัว**: ผลการอ่านทุกเครื่องส่งเข้า Google Sheet ของครู
- **เช็คเสียงก่อนอ่าน**: ลงทะเบียนเสียงนักเรียนครั้งแรก ระหว่างอ่านพี่ฮูกสุ่มขอฟังเสียง แล้วอัดเก็บไว้ให้ครูฟัง ถ้าเสียงต่างจากที่ลงทะเบียนหรือทุ้มแบบผู้ใหญ่ จะติดธง "ควรฟังซ้ำ" ให้ครู
- **ฝึกคำยาก**: คำที่เด็กสะดุดถูกเก็บไว้ แล้ววนกลับมาฝึกตามรอบ (วันนี้ → 1 วัน → 3 วัน → 7 วัน → 21 วัน)
- **ทดสอบแบบ RT**: อ่านออกเสียงคำ · อ่านข้อความจับเวลา (คำต่อนาที) · อ่านรู้เรื่อง
- **อัดเสียงหนูแล้วฟังเทียบกับพี่ฮูก**
- **โหมดห้องเรียน (ฉายจอ)**: ตัวหนังสือใหญ่ ครูเลื่อนทีละคำด้วยลูกศร/Space
- **รางวัล**: สะสมดาวเพื่อปลดล็อกชุดแต่งตัวพี่ฮูก และได้สติกเกอร์ปกนิทานที่อ่านจบ
- **ระดับความยากอัตโนมัติ** (ง่าย/ปานกลาง/ท้าทาย) จากจำนวนคำควบกล้ำ อักษรนำ การันต์ และคำอ่านไม่ตรงรูป
- **สร้างนิทานด้วย AI** (Gemini) จากคำที่อยากให้ฝึก พร้อมภาพประกอบและคำถาม
- **คลังนิทานของโรงเรียน**: ครูอัปนิทานขึ้นคลัง นักเรียนทุกเครื่องเห็นทันที
- **ติดตั้งเป็นแอปและเปิดได้แม้เน็ตไม่ดี** (ยกเว้นการฟังเสียงพูดที่ต้องใช้เน็ต)

## ตั้งค่าระบบเก็บผล (ครูทำครั้งเดียว)

ข้อมูลทั้งหมดเก็บในโฟลเดอร์ Google Drive ของโรงเรียน "เก็บไฟล์นิทานพูดได้"

1. เปิด https://script.google.com ด้วยบัญชีโรงเรียน (@ayutthaya2.go.th) → **New project**
2. ลบโค้ดเดิม แล้ววางโค้ดทั้งหมดจากไฟล์ `apps-script/Code.gs`
3. แก้บรรทัด `TEACHER_PIN` เป็นรหัสครูที่ต้องการ แล้วกดบันทึก
4. เลือกฟังก์ชัน **setup** ที่แถบด้านบน → กด **Run** → อนุญาตสิทธิ์ (Drive, Sheets)
   - ระบบจะสร้าง Google Sheet "นิทานพูดได้ - ข้อมูลผลการอ่าน" ในโฟลเดอร์ พร้อมรายชื่อตัวอย่าง 3 คน
5. **Deploy → New deployment → ประเภท Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL**
6. เปิดแอป → เปิด **โหมดครู** → "เชื่อมต่อระบบเก็บผลการอ่าน" → วางลิงก์ และใส่รหัสครู → กด **ทดสอบการเชื่อมต่อ**
7. กด **คัดลอกลิงก์สำหรับนักเรียน** ส่งให้นักเรียนเปิดครั้งแรก เครื่องนักเรียนจะเชื่อมต่อเองอัตโนมัติ

> ถ้าเมนู "Who has access" ไม่มีตัวเลือก **Anyone** แสดงว่าผู้ดูแลโดเมนจำกัดไว้ ให้ใช้บัญชี gmail ส่วนตัวสร้าง Apps Script แทน (โค้ดเหมือนเดิม แต่ต้องแก้ FOLDER_ID เป็นโฟลเดอร์ของบัญชีนั้น)

### ใส่รายชื่อนักเรียน

แท็บ **รายชื่อนักเรียน** ใน Google Sheet: ห้อง | เลขที่ | ชื่อ-สกุล | ชื่อเล่น | รหัส 4 ตัว
(ตั้งคอลัมน์รหัสเป็น "ข้อความ" เพื่อให้รหัสที่ขึ้นต้นด้วย 0 ไม่หาย)

### แท็บอื่นใน Google Sheet

| แท็บ | เก็บอะไร |
|---|---|
| ผลการอ่าน | ทุกด่านที่อ่าน: คำถูก/ช่วย/ข้าม, คำต่อนาที, ดาว, คำที่สะดุด, ผลตรวจเสียง + ลิงก์ฟังเสียง |
| ความก้าวหน้า | ด่านที่ผ่านแล้วของแต่ละคน (ใช้ปลดล็อกด่านเมื่อเปลี่ยนเครื่อง) |
| คำที่ยังอ่านไม่ได้ | คำที่สะดุดบ่อยรายคน |
| เสียงลงทะเบียน | ระดับเสียงของนักเรียนแต่ละคน |
| คลังนิทาน | นิทานที่ครูอัปขึ้นคลัง |

ไฟล์เสียงอยู่ในโฟลเดอร์ "เสียงนักเรียน/ชื่อห้อง" ในโฟลเดอร์เดียวกัน

## ข้อจำกัดที่ควรรู้

- การตรวจเสียงดูจากระดับเสียง (pitch) ไม่ใช่การยืนยันตัวตนแบบไบโอเมตริก เสียงแม่บางคนอาจใกล้เคียงเสียงเด็ก ธงจึงมีไว้ให้ครู **ฟังซ้ำ** ก่อนตัดสิน ไม่ได้บล็อกเด็ก
- การฟังเสียงพูดใช้บริการของ Google ใน Chrome ต้องต่ออินเทอร์เน็ต
- บนมือถือ/แท็บเล็ต ไมค์ใช้พร้อมกันสองระบบไม่ได้ การสุ่มตรวจเสียงจึงทำก่อนเริ่มอ่านด่าน ไม่ใช่ระหว่างอ่าน
